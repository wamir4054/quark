# Quark Website v5

Сайт больше НЕ содержит `.exe` внутри репозитория/архива.

## Скачать

Обе кнопки скачивания ведут на внешний URL:

`https://github.com/YOUR_USERNAME/YOUR_REPO/releases/latest/download/Quark-Setup-1.0.0.exe`

Перед публикацией замени `YOUR_USERNAME/YOUR_REPO` в `index.html` на свой GitHub-репозиторий.

### Рекомендуемый вариант GitHub

Загрузи `Quark-Setup-1.0.0.exe` не в обычные файлы репозитория, а как **GitHub Release → Release assets**.

Тогда сайт будет использовать:

`https://github.com/USERNAME/REPOSITORY/releases/latest/download/Quark-Setup-1.0.0.exe`

Так `.exe` не занимает место среди файлов репозитория, а кнопка сайта всегда может вести на последнюю версию установщика.
